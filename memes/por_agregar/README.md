# Memes para los sobres

Coloca aquí las imágenes que quieras convertir en cartas, o adjúntalas directamente en el chat. Acepto PNG, JPG y WebP; pueden tener cualquier tamaño porque prepararé copias ligeras para el móvil.

Si quieres, acompaña cada imagen con un nombre, una frase y una rareza. Si no, empezaré con el nombre del archivo y te mostraré la carta para revisarla.

Esta carpeta es una bandeja de entrada. Las imágenes todavía no aparecen automáticamente en la app: hay que añadirlas al catálogo de cartas y a los sobres.
